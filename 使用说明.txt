梦角传讯 iPhone 全屏版

部署前：
1. 先在原网站中导出完整备份。
2. 不要只上传 index.html；本文件夹中的文件需要一起上传，并保持在同一目录。

部署到 GitHub Pages：
1. 新建一个 GitHub 仓库，例如 dunian。
2. 将压缩包内的全部文件上传到仓库根目录。
3. 进入 Settings → Pages。
4. Source 选择 Deploy from a branch，分支选择 main，目录选择 /(root)，保存。
5. 等待网页地址生成后，用 iPhone 的 Safari 打开。
6. 点击分享 → 添加到主屏幕。

如果以前已经添加过该网址：
先删除旧的桌面图标，再从 Safari 重新添加，否则可能继续沿用旧的浏览器启动方式。

数据提醒：
新网址和原网址的本地数据互不相通。确认新版本能正常打开后，再导入之前导出的备份。
